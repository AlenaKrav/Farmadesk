# FarmaDesk

FarmaDesk is a web-based management platform designed for small pharmacies. It combines a public-facing website with private areas for patients and pharmacy staff, providing a centralized environment for managing everyday pharmacy-related tasks.

The project was developed as my final project for the Higher Vocational Education and Training program in Web Application Development (DAW).

## Overview

FarmaDesk provides pharmacies with a digital presence while also offering private management areas for different types of users.

The platform is divided into three main areas:

* **Public website**

  * Responsive and user-friendly interface.
  * Modern and minimal design.
  * Contact form for communication with patients and other users.

* **Patient area**

  * Private access for patients.
  * Management of their prescriptions.

* **Pharmacy staff area**

  * Private administration area.
  * Management of internal pharmacy tasks and operations.

## Architecture

The application follows the **Model-View-Controller (MVC)** architectural pattern, separating the application's data, presentation, and application logic into distinct components.
